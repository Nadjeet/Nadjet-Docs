# Decisions

Nadjet records technical decisions as `TD-xx` rows, and product decisions as `D-xx` in `PRD.md`. The technical file wins over older design documents.

- [Decision log](01-decision-log.md): an index of every technical decision.

Rows are never renumbered. A later decision can supersede an earlier one, so TD-03, for example, was refined by TD-37.

Open questions are tracked as `TQ-xx` in the same file. The national design has its own list in [section 2.18 of the production target](../Architecture/09-production-target.md).
